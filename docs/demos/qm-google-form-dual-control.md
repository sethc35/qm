# Shared-browser dual-control demo

[Watch the recorded Google Form demo](./qm-google-form-dual-control.mp4).

This is the Browserbase recording of the actual shared browser, not a recording of the QM chat UI.
QM spawned two real worker sessions that attached to one Browserbase session. The workers used the
same browser-side rendezvous key to type into separate fields concurrently while the page displayed
the `QM shared computer use` panel, per-agent status rows, cursors, and target rings.

- Browserbase session: `6b24b3b8-586f-46bb-b14b-6d0a2a916746`
- Worker 1 session: `a6dc7656-fd09-4457-94f7-109489a4b551`
- Worker 2 session: `22d4984d-04f3-4499-b553-cec9594af689`
- Synchronized action overlap: 5,013 ms
- Final DOM: Name, Telephone, Thai, and Comments verified
- Submission: Submit was not clicked
